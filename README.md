## Опис проєкту

Навчальний репозиторій для лабораторної роботи №3 з дисципліни
"Основи роботи з системами контролю версій" (Git/GitHub).

### Автор

Ребіженко <Andrii>

## Функціонал

- Ведення історії змін через Git
- Робота з гілками (feature, development)
- Автоматизація через GitHub Actions

## Використані команди

| Команда | Призначення |
|---|---|
| git init | ініціалізація репозиторію |
| git add | додавання файлів до індексу |
| git commit | створення коміту |
| git push | відправка змін на GitHub |
